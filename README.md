# Intelligent Document Processing — Product Specs

Product artifacts for an API-led **Intelligent Document Processing (IDP)** system
focused on multi-document share-transfer workflows.

This repository holds:
- OpenAPI specifications
- Document type schemas
- Product requirements and use-case catalog
- Postman collections for Jobs API exploration

**Code lives in sibling repositories** (kept separate on purpose):
| Repo | Role |
|------|------|
| `idp-jobs-api` | Job orchestration / workflow validation API |
| `idp-extraction-engine` | Per-document extraction + validation engine |
| `idp-assistant-ui` | Chat UI + UX prototypes |

See the curated wiki at **[idp-product-wiki](https://github.com/r123singh/idp-product-wiki)** (and mirrored under [`wiki/`](wiki/) in this repo) for product-manager artifacts (vision, journey, API design, validation model).
