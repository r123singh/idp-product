# UX Journey

Static prototypes (`prototype-minimal`) and the working `chat-ui` share one conversational metaphor.

## Flow states
1. **Initial** — centered “How can I help?” + attach
2. **Chat started** — threaded messages
3. **Files attached** — visible file chips, ready to send
4. **Processing** — input disabled; progress / document badges

## Product intent
Make a complex multi-document compliance job feel like a short conversation, while the Jobs API carries the heavy workflow state behind the scenes.
